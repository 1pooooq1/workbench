## BUG 修复：每日十问 "S is not defined"（已部署 b5b25fe）
- 线上报错截图：区块显示「⚠️ 每日十问渲染出错: S is not defined」。根因：`dailyq.js` IIFE 内直接用了 `S.get()/S.save()`、`U.esc/today/pad`、`C.btn` 等，但脚本顶部未声明这些全局引用，导致渲染时 `S` 未定义抛错。
- 修复：在 `dailyq.js` IIFE 首行补 `var U = W.U, C = W.C, S = W.S;`（与 wordstudy.js/english.js 等模块一致的作用域声明方式）。
- 版本：index.html `dailyq.js?v=20260825-1` → `?v=20260825-2`。因本地已 commit（b5b25fe）但当时推送未实际落到 origin/main（HEAD 领先 remote 1），后续补推 `0307402..b5b25fe` 成功；等待 GitHub Pages 重建后验证线上 index 已引用 20260825-2 且文件含修复行。
- 教训：新建独立 JS 模块时，若使用 `S`/`U`/`C`，必须在 IIFE 顶部显式 `var S=W.S, U=W.U, C=W.C;`，否则渲染即抛 "S is not defined"。
