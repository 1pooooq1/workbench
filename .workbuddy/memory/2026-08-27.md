## 书法练习新增「练字月历」视图（已部署 b2b87eb）
- 用户诉求（在「每日计划 → 书法练习」）：加一个月历，有记录的日子显示小圆点；点击任意日期，下方显示当天的照片和想法。
- 现况：`modules.js` 的 `calligraphySection(b)` 本来已有「练字作品记录」（上传照片 `U.Blobs` + 想法 `desc` + 心情 `mood`，存 `s.calligraphy.records[YYYY-MM-DD]=[]`），但缺月历视图。本次补齐。
- 实现：在「练字作品记录」列表之后新增 `📅 练字月历` 区块，复用 `.cal/.cal-hd/.cal-g/.cal-w/.cal-d/.dt` 样式（与 每日十问 月历同构）：
  - `drawCal()`：`calYM`、`selDate` 局部状态；`‹ ›` 翻月；网格首列周一；`U.daysInMonth` 取天数；某天 `s.calligraphy.records[dk].length>0` 则加 `.dt` 小圆点（选中日圆点变白）；点击日期 `selDate=dk` 重绘。
  - 详情卡：未选日期→提示「点击上方日期看当天照片和想法」；选中且有记录→逐条渲染 `U.Blobs.get(r.img)` 取回照片（`<img>` 限宽圆角）+ 心情 + 想法 `desc`；无记录→「这一天没有练字记录」。
  - 保存记录时 `drawRecords(); drawCal();` 双刷新，新增当天立即出现圆点。
- 版本：index.html `modules.js?v=20260825-1` → `?v=20260827-1`。git push 遇 443 中断重试多次后成功（b2b87eb）；线上已验证 index 引用 20260827-1 且文件含「练字月历」。
- 备注：用户原话"每日十问有问题"经澄清实为要在「书法练习」加月历；每日十问本身已修好（上一轮 S is not defined）。书法练习作品记录与月历共用同一份 `s.calligraphy.records` 数据，无需迁移。
